# Model Update Criteria (arXiv-Informed)

For each model refresh proposal:
1. Gather current relevant arXiv papers for architecture or inference changes.
2. Compare candidate models on benchmark quality, latency, and cost.
3. Require safety/governance impact analysis before rollout.
4. Run Phoenix/LangFuse evals and Terminal Bench gates.
5. Approve only if quality increases and reliability/cost guardrails hold.
